# athelialabs.com

The interim website of Athelia Labs LLC: one static page listing the company's products and how to
reach it, served by GitHub Pages at https://athelialabs.com. The walkable-garden site being built in
`athelia-labs-demos` replaces it when it is finished.

- `index.html` is the whole site; there is no build step.
- `CNAME` names the custom domain for GitHub Pages.
- DNS lives at Porkbun: apex A records to GitHub Pages and `www` as a CNAME to `andrescanas01.github.io`.
